# PWC Nigeria–UK Property Landing Page

Live website: https://nigeriauk.propertywealthcorp.com

## Source

This is a buildless static website. `dist/index.html` is the page, `dist/styles.css` the styles, `dist/app.js` the rental-income calculator, and `dist/assets/` contains the original and retouched images. No package installation or build is required. Serve `dist/` using any static web host.

## Hosting and future updates

The live site is hosted on ChatGPT Sites. Squarespace manages the custom domain DNS. The existing Sites project ID is `appgprj_6ac7f6b05e9c8191a0b724c5405f908b`; its configuration is in `.openai/hosting.json`.
